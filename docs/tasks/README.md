# Tarefas

Esta pasta guarda notas de trabalho em andamento que não pertencem à
documentação permanente: recortes de investigação, listas temporárias e
rascunhos de especificação ainda não aprovados.

- O andamento resumido fica em `tasks.md`, na raiz.
- Especificação aprovada de skill vai para `docs/skills/<nome>.md`.
- Resultado de avaliação vai para `docs/evaluations/<skill>-<data>.md`.
- Decisão estrutural vira ADR em `docs/decisions/`.

Nota que virou regra do projeto sai daqui e entra na documentação.
